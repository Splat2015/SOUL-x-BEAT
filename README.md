# SOUL x BEAT

An Undertale / Just Shapes & Beats inspired fan mashup: bullet-dodging boss fights to the beat, with FIGHT / ACT / ITEM / MERCY turns.

**Play in your browser:** https://splat2015.github.io/SOUL-x-BEAT/

## Modes

- **STORY**: the RPG story mode with 3 save files, 1–4 players on one screen, levels, equipment and items. (In development.)
- **SOLO**: one-player boss fights.
- **CO-OP**: 2–4 players on one screen.
- **ONLINE**: play together over the internet using a room code.

## Controls

- **Move:** WASD or the arrow keys
- **Dash:** Space or Shift
- **Confirm:** Enter / Z / A
- **Back:** X / B
- Controllers and touch controls are supported. See the Settings menu (the gear icon on the title screen).
